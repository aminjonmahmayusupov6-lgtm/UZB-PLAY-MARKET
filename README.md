# UZB-PLAY-MARKET

Neon ko‘k-qora dizayndagi bepul ilovalar marketi uchun boshlang‘ich frontend.

## Fayllar
- `index.html` — asosiy sahifa va modal oynalar
- `style.css` — moslashuvchan neon dizayn
- `script.js` — qidiruv, kategoriya filtri va demo ilova formasi

## Ishga tushirish
`index.html` faylini brauzerda oching yoki statik hostingga joylang.

## Hozirgi holat
Bu frontend prototip. Google orqali haqiqiy kirish, ilovalarni serverga yuklash, ma’lumotlar bazasi, doimiy saqlash, moderatsiya va xavfsiz yuklab olish tizimi hali backend hamda OAuth sozlamalarini talab qiladi. Demo formaga kiritilgan ilovalar faqat joriy sahifada ko‘rinadi.

## Keyingi bosqich
Firebase/Supabase yoki alohida backend, Google OAuth, fayl saqlash va admin moderatsiyasini ulash.
